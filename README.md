# iFilms Media

Website source for iFilms Media, including HTML pages, styles, JavaScript, fonts, images, and video assets.

## Run locally

From the project directory, run:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Open http://localhost:8000 in your browser.

## Project structure

- `index.html`: homepage
- Other root HTML files: service, portfolio, and company pages
- `assets/`: styles, scripts, fonts, images, and videos
- `Version/`: additional project assets
- `robots.txt` and `sitemap.xml`: search engine files

The website can be served by a static web server. The optional `phpinfo.php` endpoint requires PHP.
